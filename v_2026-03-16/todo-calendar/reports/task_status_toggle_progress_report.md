### 3. 数据更新 ✅

**要求**:
- [x] 点击"完成" → 更新任务状态为 completed
- [x] 点击"未完成" → 更新任务状态为 pending
- [x] 实时更新数据库

**实现详情**:

**前端信号流程**:
```
用户点击复选框
  ↓
TaskItemWidget.checkbox.toggled 信号
  ↓
TaskListWidget.task_completed.emit(task_id, checked)
  ↓
MainWindow._on_task_completed(task_id, completed)
  ↓
TaskService.mark_complete() 或 update_task()
  ↓
SQLite 数据库更新
```

**后端实现**:
```python
# src/services/task_service.py
def mark_complete(self, task_id: int) -> Optional[Task]:
    task = self.get_task(task_id)
    if task:
        task.mark_complete()  # status=2, completed_at=now
        self.session.commit()
    return task
```

### 4. 统计同步 ✅

**要求**:
- [x] 状态变更后立即更新统计面板
- [x] 统计面板显示：总任务数、已完成数、待处理数、完成率

**实现详情**:

**统计更新流程**:
```python
# src/ui/main_window.py
def _on_task_completed(self, task_id: int, completed: bool):
    if completed:
        self.task_service.mark_complete(task_id)
    else:
        self.task_service.update_task(task_id, status=0, completed_at=None)
    
    # 实时更新 UI
    self._refresh_task_list()  # 刷新任务列表
    self._update_stats()       # 刷新统计面板
```

**统计面板显示**:
- Total (总任务数)
- Completed (已完成数) - 绿色显示
- Pending (待处理数) - 橙色显示
- Rate (完成率) - 百分比
- Progress Bar (进度条) - 可视化展示
