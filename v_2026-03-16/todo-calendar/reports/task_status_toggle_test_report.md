### 2. 点击后状态立即切换

**测试结果**: ✅ 通过

**验证详情**:
- 点击复选框触发 `task_completed` 信号
- 信号传递到主窗口的 `_on_task_completed` 方法
- 后端调用 `mark_complete()` 或 `update_task()` 更新数据库
- 任务列表立即刷新

**代码流程**:
```
用户点击复选框
  ↓
TaskItemWidget.checkbox.toggled 信号
  ↓
TaskListWidget.task_completed.emit(task_id, checked)
  ↓
MainWindow._on_task_completed(task_id, completed)
  ↓
TaskService.mark_complete() 或 update_task()
  ↓
数据库更新
  ↓
刷新 UI
```

**代码位置**:
- `src/ui/task_list.py` 第 89-92 行 - 信号连接
- `src/ui/main_window.py` 第 362-368 行 - 状态处理
- `src/services/task_service.py` 第 169-184 行 - 数据库更新

### 5. 数据持久化（重启后状态保留）

**测试结果**: ✅ 通过

**验证详情**:
- 使用 SQLite 数据库存储任务状态
- `Task` 模型的 `status` 字段：
  - `0` = 待办 (pending)
  - `1` = 进行中 (in progress)
  - `2` = 已完成 (completed)
- `completed_at` 字段记录完成时间
- 重启应用后数据正确加载

**代码位置**:
- `src/models/task.py` 第 15-22 行
```python
status = Column(Integer, default=0, comment='状态：0=待办，1=进行中，2=已完成')
completed_at = Column(DateTime, comment='完成时间')
```
- `src/models/task.py` 第 30-33 行 - `mark_complete()` 方法
