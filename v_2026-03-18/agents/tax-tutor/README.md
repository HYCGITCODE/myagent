# 税务学习导师 Agent

> **高效规划 + 动态适配，助你高分通关！** 📚

---

## 快速启动

### 1. 会话初始化
```bash
# 方式 1: 通过 OpenClaw 主会话 spawn 子代理
openclaw sessions spawn --runtime subagent --agent tax-tutor --mode session

# 方式 2: 直接在工作区激活
cd /home/admin/.openclaw/workspace/agents/tax-tutor
# 加载配置文件（SOUL.md, IDENTITY.md, TOOLS.md, USER.md）
```

### 2. 首次使用
Agent 会自动加载配置文件并显示欢迎语：
```
您好！我是您的税务学习导师 📚
专注 CPA/税务师备考规划，助您高效通关！

我可以帮您：
✅ 定制弹性学习计划
✅ 诊断薄弱项并针对性突破
✅ 提供真题密训与模拟考试
✅ 碎片时间学习资源推荐

请告诉我您的备考目标（如："规划 CPA 会计 3 个月学习计划"）
```

## 核心功能

| 功能 | 触发词 | 说明 |
|------|--------|------|
| 📋 学习规划 | `规划 [目标] 学习计划` | 生成阶梯式弹性计划 |
| 🔍 薄弱诊断 | `我的薄弱点是什么？` | AI 分析错题，定位盲区 |
| ⚙️ 路径调整 | `优化学习路径` | 根据进度动态调整 |
| 📚 真题题库 | `使用真题题库` | CPA/税务师历年真题 |
| 🎬 视频课程 | `观看视频 [知识点]` | 5-10 分钟短视频课 |
| 📝 模拟考试 | `启动模拟考试 [科目]` | 全真模拟机考环境 |
| 📊 进度跟踪 | `查看进度` | 可视化学习曲线 |

## 扩展开发

### 添加新工具
1. 在 `TOOLS.md` 中定义工具功能与调用方式
2. 在 `SOUL.md` 中更新能力定义
3. 在 `USER.md` 中添加触发词

### 调整对话风格
修改 `USER.md` 中的"对话风格"与"异常处理"部分

### 集成外部 API
在 `TOOLS.md` 的"外部 API"部分配置 API 密钥与端点
